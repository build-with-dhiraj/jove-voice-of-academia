# What you are deciding

Per Voice of Academia — System Design spec D1 + D2, you must decide:

1. **Overall sentiment** of the comment: ``positive`` | ``neutral`` | ``negative`` | ``mixed``.
2. **One or more theme assignments** — each is a pair ``(theme, sentiment)``. A single comment can produce multiple assignments across sentiments. Spec D1 example:
   - *"the videos are great but the fee is outrageous"* →
     ``[{{"theme": "video_format", "sentiment": "positive"}}, {{"theme": "author_fees", "sentiment": "negative"}}]``
3. **Product attribution** for v1 = JoVE-only: always ``"journal"`` if the comment discusses JoVE; ``"out-of-scope"`` otherwise. Do NOT use ``"eoe"``, ``"visualize"``, ``"research-general"``, ``"other-journal"`` in v1.
4. **Journal named** in the comment — exactly ``"JoVE"`` (when the comment names JoVE under any alias, e.g. "Jove", "Journal of Visualized Experiments", "jove.com", "MyJoVE") or ``null``.

# Multi-theme assignment rules

- **Allowed** when the comment expresses two or more distinct ideas across different themes. The classic test case is a "praise X, criticize Y" comment: emit two assignments.
- **Mutually exclusive within a sentiment bucket** per spec D2: do NOT emit two themes for the same sentiment unless the comment genuinely contains two clearly separable ideas. When in doubt, pick the single best-fitting theme for each sentiment. Example: *"JoVE is a sketchy journal that's basically vanity publishing"* is ONE idea — pick ``legitimacy`` (negative), not ``[legitimacy, peer_review_quality]``.
- **Emerging / Other fallback** per spec D2: if no canonical theme fits with high confidence, emit a single assignment ``{{"theme": "emerging_other", "sentiment": "<the sentiment>"}}``. Do NOT force-fit into a canonical theme.

# Sentiment guidance

- ``positive`` — the comment praises, recommends, or endorses (about a specific theme).
- ``negative`` — the comment criticizes, complains, or warns against.
- ``neutral`` — descriptive without valence, or a question/observation without a clear judgment.
- ``mixed`` (OVERALL sentiment only — not per-theme) — the comment expresses both positive and negative claims overall. Per-theme sentiment is always one of ``positive | neutral | negative``.
